## 選海外 VPS 之前，先回答三個問題

搜「海外 VPS 推薦」的人，大多一上來就問哪家便宜，但真正決定用起來順不順的是下面三件事，順序別搞反。

- **給誰用？** 讀者、客戶主要在大陸或亞洲，線路品質排第一；使用者集中在歐美或日本，機房離他們近排第一。
- **拿來做什麼？** 建站、外貿、開發測試、交易下單，對延遲、穩定性和 IP 的要求完全不同。交易類業務對延遲最敏感，建站反而容錯空間大。
- **能鎖多長的付費週期？** 年付、季付單價低但資金一次鎖死；月付、按小時計費靈活但單價高。同一筆預算，週期選擇能讓實際單價差出好幾倍。

大陸訪問海外主機的速度，主要由「回國線路」決定，而常見的優化線路基本能和三家運營商對上號：電信使用者認準 CN2 GIA，聯通使用者看 CUII，移動使用者對應 CMI／CMIN2。線路買錯，頻寬再大也救不回晚高峰的卡頓。

## 常見問題

**海外 VPS 需要備案嗎？**

不需要。備案只針對託管在國內的網站，海外 VPS 買好後直接就能建站。這也是香港和美國主機用戶特別多的原因——離得近、速度快，還免備案。

**海外 VPS 和虛擬主機有什麼區別？**

虛擬主機是把一台實體伺服器分隔成若干份共享出售，通常只能託管網站，價格便宜但效能有限，大多還是共享 IP；VPS 把 CPU、記憶體、儲存都獨立分隔，每台有獨立 IP，可以當獨立伺服器用。只放網站，虛擬主機夠用；要自建網路環境、跑應用，就直接上 VPS。

**香港、日本、美國機房怎麼選？**

看使用者在哪。香港離大陸最近、延遲最低，適合大陸使用者為主的業務；東京是亞太網路樞紐，到首爾約 30ms、香港約 50ms、新加坡約 70ms，一台機器能覆蓋大半個亞太；美國機房 IP 資源多、價格低，適合面向歐美或需要美國 IP 的場景，選 CN2 GIA 線路就能兼顧大陸訪問速度。

**哪些海外 VPS 商家支援支付寶？**

搬瓦工、Vultr、Hostwinds、Hostdare、LOCVPS、V5.NET 等都支援支付寶付款。不想用傳統支付方式的話，Arct Cloud 接受比特幣、以太坊、USDT 等加密貨幣。
